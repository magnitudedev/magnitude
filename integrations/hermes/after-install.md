Magnitude is installed.

Start `hermes`, then use `/magnitude-setup` for the setup prompt or run
`magnitude setup` in your terminal if the CLI is already installed.

Desktop: enable Magnitude under Settings → Plugins, then restart the gateway.
The Magnitude status-bar button opens model controls and setup instructions.

Installing this plugin does not install the Magnitude CLI, download a model,
change your selected provider, or send a chat message.
