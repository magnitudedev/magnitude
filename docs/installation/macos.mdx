## Requirements

- macOS 15 Sequoia or later.
- An Apple Silicon or Intel Mac.
- Free disk space for the app and the models you download.

Apple Silicon uses Metal GPU acceleration. Intel Macs use CPU inference. See [Hardware](/hardware) for memory and performance guidance.

## Download the installer

1. Visit [Download Magnitude](https://magnitude.dev/download?os=macos#downloads).
2. Choose the download for your Mac. If you're unsure, open **Apple menu → About This Mac**: a chip named Apple M1, M2, or another M-series chip is Apple Silicon; an Intel processor uses the Intel download.
3. Open the `.dmg` and drag **Magnitude** into **Applications**.
4. Open Magnitude from Applications, then follow [Quick start](/get-started). Opening the app registers the CLI; use a new terminal for the `magnitude` command.

## Install from the terminal

To install the desktop app from a terminal:

```sh
curl -fsSL https://magnitude.dev/install.sh | sh -s -- --desktop
```

The installer selects Apple Silicon or Intel automatically, verifies the download, installs Magnitude in `/Applications`, and registers the `magnitude` CLI. Open a new terminal to use the command.

## Install the CLI only

For a Mac that serves other computers or apps without the desktop app:

```sh
curl -fsSL https://magnitude.dev/install.sh | sh
```

This installs only the CLI, into `~/.magnitude/cli`, with the `magnitude` command in `~/.magnitude/bin`. It needs no administrator password and updates itself while `magnitude serve` runs. Open a new terminal, then run `magnitude serve`. To keep it running in the background, see [CLI only](/installation/cli-only#keep-it-running-in-the-background). Installing the desktop app later replaces the CLI-only install.

## Updates and removal

Use **Settings → About** to download and install updates. Restarting to update stops the running model and service.

To remove the app, quit Magnitude and move it from Applications to Trash. To remove a CLI-only install, see [CLI only](/installation/cli-only#uninstall). Your downloaded models and settings live separately under `~/.magnitude`; removing the app does not mean that data has been deleted. Keep that folder if you intend to reinstall.
