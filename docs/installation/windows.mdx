## Requirements

- Windows 10 version 1809 or later, or Windows 11.
- An x64 system for the native Windows build.
- Free disk space for the app and downloaded models.

The current Windows build supports CPU inference and compatible NVIDIA CUDA or Vulkan GPUs on Windows. A ROCm backend and native Windows ARM64 build are not available. See [Hardware](/hardware).

## Download and install

1. Download the Windows installer from [Download Magnitude](https://magnitude.dev/download).
2. Run the `.exe` and complete installation.
3. Open Magnitude and follow [Get started](/get-started).

The installer installs for your user account under `%LOCALAPPDATA%\Programs\Magnitude`.

## Updates and removal

Use **Settings → Application updates** to check for updates. **Restart to update** stops local inference while the application is replaced.

Uninstall Magnitude through Windows **Settings → Apps**. Downloaded models and settings are stored separately in `%USERPROFILE%\.magnitude`; keep them if you intend to reinstall.
