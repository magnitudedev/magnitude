## Requirements

- Windows 10 version 1809 or later, or Windows 11.
- An x64 system for the native Windows build.
- Free disk space for the app and downloaded models.

The current Windows build supports CPU inference and compatible NVIDIA CUDA or Vulkan GPUs on Windows. See [Hardware](/hardware).

## Download the installer

1. Download the Windows installer from [Download Magnitude](https://magnitude.dev/download?os=windows#downloads).
2. Run the `.exe` and complete installation.
3. Open Magnitude and follow [Quick start](/get-started).

The installer installs for your user account under `%LOCALAPPDATA%\Programs\Magnitude`.

## Install from PowerShell

To install the desktop app from PowerShell:

```powershell
& ([scriptblock]::Create((irm https://magnitude.dev/install.ps1))) -Desktop
```

The script verifies the download and runs the Windows installer silently. It includes the desktop app and CLI, and makes `magnitude` available in the current PowerShell session. Open a new terminal to use it in other shells that were already running.

## Install the CLI only

For a machine that serves other computers or apps without the desktop app:

```powershell
irm https://magnitude.dev/install.ps1 | iex
```

This installs only the CLI, into `%USERPROFILE%\.magnitude\cli`, with the `magnitude` command in `%LOCALAPPDATA%\Programs\Magnitude CLI`. It needs no administrator rights and updates itself while `magnitude serve` runs. Run `magnitude serve` to serve; to keep it running in the background, see [CLI only](/installation/cli-only#keep-it-running-in-the-background). Installing the desktop app later replaces the CLI-only install.

## Updates and removal

Use **Settings → About** to check for updates. **Restart to update** stops local inference while the application is replaced.

Uninstall Magnitude through Windows **Settings → Apps**. To remove a CLI-only install, see [CLI only](/installation/cli-only#uninstall). Downloaded models and settings are stored separately in `%USERPROFILE%\.magnitude`; keep them if you intend to reinstall.

Agents installed inside WSL need a small amount of configuration; see [Windows and WSL](/api/windows-wsl).
