## 1. Install Magnitude

[Download Magnitude](https://magnitude.dev/download), install it, and open the app.

Need help installing? See the guide for [macOS](/installation/macos), [Windows](/installation/windows), or [Linux](/installation/linux).

## 2. Download a model

Open **Discover**, select a recommendation, and click **Download**. Start with **Balanced**, or adjust the slider toward speed or intelligence.

## 3. Connect your agent

Open **Connections**, find your installed agent, and click **Connect**. Open or restart the agent, select a Magnitude model, and start working.

See your agent’s [integration guide](/integrations/overview) for details. Keep Magnitude running; it loads the model when needed.

Using a dedicated machine for inference? See [Remote server](/remote-server).
