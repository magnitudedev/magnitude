## 1. Install Magnitude

[Download Magnitude](https://magnitude.dev/download#downloads) for macOS, Windows, or Linux and open the installer.

Need help installing? See the guide for [**macOS**](https://docs.magnitude.dev/installation/macos), [**Windows**](https://docs.magnitude.dev/installation/windows), or [**Linux**](https://docs.magnitude.dev/installation/linux). Setting up a server? See [**CLI only**](https://docs.magnitude.dev/installation/cli-only). Running in a container? See [**Docker**](https://docs.magnitude.dev/installation/docker).

## 2. Choose a model

The first time you open Magnitude, it reads your hardware, finds models already on your computer, and measures how models run on it. It then recommends up to three models that run well here.

Choose one and click **Download**. When the download finishes, Magnitude loads the model and opens **Chat**, so you can try it right away.

To find other models later, open **Models** and click **Explore models** to search Hugging Face. See [Models](/models).

## 3. Connect your agent

Open **Connections**, find your agent, and click **Connect**. Choose a model on its card, then copy the command shown and run it in your terminal from your project folder.

In a browser, such as with the [CLI only](/installation/cli-only), **Connections** gives you a setup prompt to paste into your agent instead.
