## 1. Install Magnitude

<Tabs>
<Tab title="macOS / Linux">
```sh
curl -fsSL https://magnitude.dev/install.sh | sh
```
</Tab>
<Tab title="Windows PowerShell">
```powershell
irm https://magnitude.dev/install.ps1 | iex
```
</Tab>
</Tabs>

Includes the desktop app and CLI. You can also [download manually](https://magnitude.dev/download#manual-downloads).

Need help installing? See the guide for [**macOS**](https://docs.magnitude.dev/installation/macos), [**Windows**](https://docs.magnitude.dev/installation/windows), or [**Linux**](https://docs.magnitude.dev/installation/linux).

## 2. Download a model

Open Magnitude and go to **Discover**. Choose a recommended model and click **Download**.

## 3. Connect your agent

Open **Connections**, find your agent, and click **Connect**. Copy the command shown and paste it into your terminal to start your agent.

Using a dedicated machine for inference? See [**Remote server**](https://docs.magnitude.dev/remote-server).
