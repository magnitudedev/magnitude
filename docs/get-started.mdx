## Install the desktop app

Download a desktop installer available for your platform from the [Magnitude releases](https://github.com/magnitudedev/magnitude/releases). Install and open the application. Installing the npm CLI alone does not install the desktop application.

## Choose a model

1. Open **Discover** to see curated recommendations for your machine.
2. Adjust the speed-to-intelligence preference and compare estimated memory and performance.
3. Download a model. Track its download and load or stop it in **My Models**.
4. Open **Connections** and connect an external harness.

Connect writes configuration and the supported skill or plugin files. It does not launch the harness. Open your harness yourself and select the configured Magnitude model.

Supported connectors include Pi, OpenCode, Hermes, OpenClaw, Codex, Claude Code, Oh My Pi, and Cline. The connection status checks the actual managed configuration; repair a disconnected configuration from Connections.

## Background operation

Closing the window leaves the application and its service running. Use **Quit Magnitude** to stop the whole application, including inference. **Stop model** unloads the model while keeping the service available.

**Status** distinguishes the running service from a loaded model. **Settings** controls Light, Dark, or System appearance and launch at login. Login startup opens the background process and tray without showing a window. Some Linux desktops do not provide a supported tray host; you can still reopen the application from the applications menu.

## Optional headless CLI

For agents and scripts:

```sh
npm install -g @magnitudedev/cli
magnitude docs cli
magnitude service status
```

The CLI controls the same desktop-owned service and has no interactive onboarding or built-in agent harness. `magnitude service start` starts the app in the background and waits for its service. `magnitude app open` explicitly opens the window.

<Note>
  Codex and Claude Code connections use Magnitude's local gateway while connected, including when using hosted models. Keep Magnitude running, or disconnect the integration before quitting it.
</Note>
