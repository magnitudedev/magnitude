## Install

<Tabs>
  <Tab title="npm">
    ```sh
    npm install -g @magnitudedev/cli
    ```
  </Tab>
  <Tab title="bun">
    ```sh
    bun add -g @magnitudedev/cli
    ```
  </Tab>
  <Tab title="pnpm">
    ```sh
    pnpm add -g @magnitudedev/cli
    ```
  </Tab>
  <Tab title="yarn">
    ```sh
    yarn global add @magnitudedev/cli
    ```
  </Tab>
</Tabs>

## Run Magnitude

From the directory you want Magnitude to work in:

```sh
cd your-project
magnitude
```

On first launch, Magnitude profiles your hardware and ranks compatible models. Tune Fast-to-Smart, choose a model, and Magnitude downloads, configures, and runs it inside the agent. [Learn about local models →](/models)

Once the model is ready, ask Magnitude to work in the current directory. It can inspect and edit files, run commands, and execute scripts. Add [skills](/skills) to extend it with support for browsers, spreadsheets, presentations, documents, PDFs, and more.

## Windows

Magnitude requires WSL on Windows. Native Windows is not currently supported.

```powershell
wsl --install
```

Restart your computer, open WSL, and follow the installation steps above.

## Terminal

Magnitude renders best in a modern terminal emulator such as [Ghostty](https://ghostty.org) or [Kitty](https://sw.kovidgoyal.net/kitty/). The default macOS Terminal has limited color support and may look different.

## Enable web search

Magnitude can use [Exa](https://exa.ai) to search the web. Create an Exa API key, then set it before starting Magnitude:

```sh
export EXA_API_KEY="your-api-key"
magnitude
```
