Magnitude Cloud adds hosted open models and Exa web search to the same coding agent you use with local models. It has **zero data retention**, so your prompts and code are not stored or used for training.

## What is included

- Access to leading open models that may be too large for your machine, including GLM 5.2, Kimi K3, and DeepSeek V4
- Generous rolling usage limits across five-hour, weekly, and monthly windows
- Fast, reliable hosted inference using native model weights
- Exa web search for external research

## Connect Magnitude Cloud

Subscribe at [app.magnitude.dev](https://app.magnitude.dev), create an API key, then open `/settings → Cloud` and add the key. Cloud models appear alongside local models in the **Models** menu.

You can switch between local and cloud models without changing the conversation interface or configuring a separate provider.

## Subscription and usage

Magnitude Cloud costs \$10 for the first month, then \$20 per month after that. You can cancel at any time.

The subscription includes generous rolling usage limits across five-hour, weekly, and monthly windows. Open `/usage` or `/limits` in the CLI to see remaining usage and reset times, or visit the [Magnitude Cloud console](https://app.magnitude.dev).
