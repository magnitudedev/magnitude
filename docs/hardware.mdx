title: "Hardware"

Magnitude measures your machine and recommends models that run well on it. Start with those rather than choosing a model by parameter count. To see what Magnitude found, open **Settings → General → Your machine**, or run `magnitude hardware`.

## Supported configurations

| Machine | Inference support |
| --- | --- |
| Apple Silicon Mac | Metal GPU acceleration |
| Intel Mac | CPU |
| Windows x64 | CPU, supported NVIDIA CUDA GPUs, or supported Vulkan GPUs |
| Linux x64 or ARM64 | CPU, supported NVIDIA CUDA GPUs, or supported Vulkan GPUs |

See [macOS](/installation/macos), [Windows](/installation/windows), and [Linux](/installation/linux) for OS requirements and installers. In [Docker](/installation/docker), containers reach NVIDIA GPUs through the NVIDIA Container Toolkit and AMD and Intel GPUs through Vulkan. On any Mac, Docker runs containers in a Linux virtual machine that can't reach the Apple GPU, so the container runs models on the CPU; use the [macOS app](/installation/macos) for GPU speed.

## Apple Silicon

Apple Silicon shares memory between the CPU and GPU, so the GPU can use far more memory than a typical laptop's graphics card. macOS and your other apps use the same memory, so a Mac with 32 GB does not have all 32 GB for a model. If a model fails to load, close memory-heavy apps or choose a smaller quant.

Metal comes with macOS; you don't need a separate GPU toolkit.

## NVIDIA GPUs

On Linux and Windows, Magnitude uses CUDA on NVIDIA GPUs from the Ampere generation (RTX 30 series, A100) and newer. A dedicated GPU's memory is separate from your RAM: a machine with 64 GB of RAM and an 8 GB GPU has 8 GB of GPU memory, not 72 GB. Install your GPU's NVIDIA driver; you don't need the CUDA toolkit. To check that the driver sees the GPU:

```sh
nvidia-smi
```

## AMD, Intel, and other Vulkan GPUs

On Linux and Windows, Magnitude uses Vulkan 1.1 or later for other GPUs. Use your system's graphics driver and Vulkan runtime. Magnitude does not use ROCm.

## CPU only

Magnitude runs models without a supported GPU, including on Intel Macs. It can't measure speed on every CPU, so recommendations may say a model fits with its speed unknown. Smaller models and quants respond faster.

## How a model fits

Each quant shows where it runs on your machine:

- **In GPU or unified memory:** the fastest.
- **Experts streamed from RAM or SSD:** a mixture-of-experts model larger than your GPU memory can still run, with the experts it isn't using kept in RAM or read from your SSD. It's slower than a model that fits entirely.
- **Doesn't fit:** too large for this machine.

When a model's full context doesn't fit in memory, Magnitude serves it with a shorter one: the largest power of two that fits, which the app shows in orange, such as **64K context**. It never goes below 32K, because a coding agent's prompt and tools fill much of a smaller context.

On a machine with several GPUs, a model runs on one GPU.
