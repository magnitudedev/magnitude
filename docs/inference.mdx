## Model loading

Magnitude loads models on demand and unloads them when idle or memory is tight. The first request can take longer while the model loads. To load it ahead of time, click **Load model** in **My Models**.

## Context and memory

Longer conversations use more memory and take longer to process. If responses slow down, try a fresh conversation. If a model won't load, check **Status**, close memory-heavy apps, or choose a smaller model.

## Prompt caching

Magnitude reuses previously processed context when possible, helping later turns start faster. Switching models or changing earlier conversation content can reduce cache reuse.

## Speculative decoding

Supported models use **MTP**, **DFlash**, or **DSpark** to propose tokens for the main model to verify, speeding up generation. Magnitude handles the setup automatically.

## Performance and usage

Open **Usage** to view local inference activity by model, for **Today** or **All time**.

- **Input tokens:** prompt and conversation tokens, including cached input.
- **Cached input:** tokens reused from cache; a subset of input tokens.
- **Output tokens:** generated tokens.
- **Generation speed:** output tokens per second.
- **Time to first token:** time before the response starts.

Loading and prompt processing can delay the first token even when generation is fast. Running several agents at once shares your machine's resources and can slow responses.
