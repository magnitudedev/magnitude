title: Why Magnitude
description: "The easiest way to code with local models"
icon: compass
---

Magnitude is an open source coding agent and inference engine built for local models. It handles the difficult parts of choosing, configuring, and running them so you can focus on your code.

- **Automatic model setup.** Magnitude detects and profiles your hardware, recommends configurations that fit, and handles downloading and setup.

- **Local inference built for coding agents.** Magnitude starts and manages its Rust inference engine for you, so there is no model server or set of llama.cpp options to configure.

- **Consistent behavior across models.** It normalizes reasoning, tool use, chat templates, and conversation history so different local models work consistently with the coding agent.

- **A complete coding agent.** Magnitude can inspect and edit your codebase, run commands, work with files and images, manage long conversations, and delegate work to other agents.

- **Local by default, cloud when you need it.** Run local models for free, add Magnitude Cloud for larger open models with zero data retention.

- **Open source.** Magnitude is available under the [Apache 2.0 license](https://github.com/magnitudedev/magnitude/blob/main/LICENSE).
