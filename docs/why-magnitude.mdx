Today's agents are local. The model isn't. Every prompt, every file, every secret gets sent straight to Anthropic and OpenAI. If it runs in the cloud, it isn't yours.

Magnitude is built around local models and runs the whole stack itself. The inference engine is part of the agent, so the models run inside it, right on your MacBook.

It lives in your terminal, and setup is one command. Magnitude profiles your hardware and shows you which models fit, with the trade-offs between quality, speed, and memory. Pick one and start working. No separate inference server or endless configuration.

Out of the box, it can use your shell, edit files, and run scripts. Add [skills](/skills) and it can work with Excel, PowerPoint, PDFs or Chrome.

Use it for everyday work:

- Analyze sensitive data
- Manage private notes
- Review code and logs
- Search and organize files
- Build docs or slides
- Create automation scripts

Magnitude is open source under the [Apache 2.0 license](https://github.com/magnitudedev/magnitude/blob/main/LICENSE).
