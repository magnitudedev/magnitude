Install Magnitude, choose a model recommended for your machine, and start coding.

## Local model coding without the setup

Local coding normally means finding a model, choosing a quantization, installing a runtime, tuning it for your hardware, connecting it to an agent, and keeping the stack working.

Magnitude handles that setup for you. It profiles your hardware, recommends model configurations that fit, then downloads, configures, and runs the model you choose. There is no separate model server or set of runtime options to configure.

## Switch models without rebuilding your setup

Local models use different reasoning formats, tool-call formats, chat templates, and conversation-history conventions. Magnitude handles those differences automatically, so switching models does not require reconfiguring the agent or connecting a different runtime.

Local and cloud models appear together in the same model menu and use the same conversation interface. Run models entirely on your machine, or switch to Magnitude Cloud when you need a model too large for your hardware.

## A complete coding agent

Magnitude can inspect and edit your codebase, run commands, work with files and images, manage long conversations, and delegate work to other agents.
