Today's agents are local. The model isn't. Every prompt, every file, every secret gets sent straight to Anthropic and OpenAI. If it runs in the cloud, it isn't yours.

Magnitude is built around local models and runs the whole stack itself. The inference engine is part of the agent, so the models run inside it, right on your MacBook.

It lives in your terminal, and setup is one command. Magnitude profiles your hardware and shows you which models fit, with the trade-offs between quality, speed, and memory. Pick one and start working. No Ollama, no config files, no server to babysit.

Out of the box, it can use your shell, edit files, and run scripts. Add [skills](/skills) and it can work with Excel and PowerPoint or drive your logged-in Chrome browser.

Use it for everyday work:

- Analyze usage data and customer calls
- Grep production logs and diagnose failures
- Review PRs and fix bugs
- Search and summarize internal docs
- Build technical docs or company slides
- Automate repetitive tasks with scripts

Magnitude is open source under the [Apache 2.0 license](https://github.com/magnitudedev/magnitude/blob/main/LICENSE).
