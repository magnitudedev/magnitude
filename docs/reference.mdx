The desktop app includes the `magnitude` CLI, and the CLI-only install provides it alone for servers and headless use (see [Remote server](/remote-server)). In a new terminal, run:

```sh
magnitude --help
```

Running `magnitude` without a subcommand prints help. No npm installation is required.

## Run Magnitude

| Command | Purpose |
| --- | --- |
| `magnitude app open` | Show the desktop window. |
| `magnitude serve` | Run the service in the foreground without opening Desktop. |
| `magnitude status` | Check whether Magnitude is running and inspect service and model status. |

Model, hardware, and connection setup commands require a running Desktop or `magnitude serve`.
Stop a foreground server with Ctrl+C. While Desktop is open it serves, and `serve` waits until Desktop quits, then resumes.
Only one `serve` can run under the same user account. To keep `serve` running in the background at login or at boot, see [Remote server](/remote-server#keep-it-running-in-the-background).

Use **Launch at login** in Desktop Settings for login startup, and **Quit Magnitude** to stop Desktop.

## Find and download models

Assessment and downloads run in the background. Use status commands to check progress.

| Command | Purpose |
| --- | --- |
| `hardware` | Inspect detected hardware and memory. |
| `models list` | List the models on this computer with their quant, size, speed, context, source and status, and assessment progress. `--all` adds models that can't run and hidden ones. |
| `models recommend` | Show the tested models recommended for this computer, each at the quant chosen for it with its ladder of quants; a limit of 10 by default. |
| `models search <query>` | Search Hugging Face, with each result's base model and how its recommended quant runs here. |
| `models show <model>` | For a model ID, Hugging Face link or `owner/repo[:QUANT]`, show every quant with its size, speed, context and placement, and for the chosen quant where its bytes go and its speed at each context depth. |
| `models pull <model>` | Download or update a model by ID, or add one from Hugging Face by link or `owner/repo[:QUANT]`. |
| `models cancel <model-id>` | Cancel a download or model update. |
| `models load <model-id>` | Load a downloaded model into memory. |
| `models stop [model-id]` | Stop a model, or the active one, without deleting it. |
| `models rm <model-id>` | Remove a model Magnitude downloaded; a model found in another app's folder is hidden instead. |
| `models families` | List the model families Magnitude runs. |

Prefix each command with `magnitude`. Use `--country US` with `models recommend` to recommend only models from developers in one country, and `--limit` to show fewer.

## Connections

| Command | Purpose |
| --- | --- |
| `magnitude connections list` | Inspect installed agents and connection state. |
| `magnitude connections connect <harness>` | Configure an agent on this computer, for you. |
| `magnitude connections sync [harness]` | Refresh one or all configured integrations. |
| `magnitude connections remove <harness>` | Disconnect an agent. |

`connections connect` accepts `--set-model <model-id>` to select a model and `--install-skill` to install or refresh its Magnitude skill. Skill installation is automatic for Pi.

Harness IDs: `pi`, `opencode`, `hermes`, `openclaw`, `codex`, `claude-code`, `oh-my-pi`, and `cline`. See [Integrations](/integrations/overview) for agent-specific instructions.

## Updates

| Command | Purpose |
| --- | --- |
| `magnitude update` or `magnitude update check` | Check for a newer Magnitude release. |
| `magnitude update status` | Read update state without starting the app. |
| `magnitude update download` | Download the available update and wait until it is ready to install. |
| `magnitude update install` | Install a prepared update; stop inference and restart Desktop if it was running. |
| `magnitude update discard` | Remove a retained update download. |

These commands update Desktop and its CLI together, or the CLI-only install. Checking, downloading, inspecting, or discarding an update does not open Desktop.

A CLI-only install updates itself while `magnitude serve` runs: it downloads updates, waits until no inference request is running, then installs and restarts in place. With `autoDownloadUpdates` set to `false`, run `magnitude update install` to install one. Failed attempts require an explicit `update install` retry. Desktop installation on Linux may require administrator authorization.

## Help

Use `--help` after any command to see its options. `magnitude --version` prints the installed CLI version. `magnitude docs` lists documentation bundled with the CLI, and `magnitude docs cli` prints its command guide.

## Configuration

Settings are stored in `~/.magnitude/config.json`. See [Configuration file](/reference/configuration-file).
