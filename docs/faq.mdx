## What is Magnitude?

Magnitude is an open source local inference server for agents. It profiles your hardware, recommends model configurations, then downloads, tunes, and runs them. Use Magnitude Harness or connect another supported harness.

## What hardware do I need?

There is no fixed minimum. Magnitude profiles the available hardware and recommends configurations that fit. More memory supports larger models and contexts.

## How is it different from Ollama or LM Studio?

Ollama and LM Studio run the model configuration you choose. Magnitude profiles the machine, recommends exact model, quantization, and context combinations, estimates their performance, and tunes the runtime. It also manages model residency, memory, and concurrency for agent workloads.

## Which harnesses work with it?

Magnitude supports Magnitude Harness, Pi, OpenCode, Hermes, OpenClaw, Codex, Claude Code, Oh My Pi, and Cline. Setup connects and launches the harness you choose.

## Do I need to manage Magnitude after setup?

No. Magnitude runs in the background and manages the selected model automatically. Revisit it when you want to try a new or different model or need to diagnose a problem. Your agent can use the Magnitude CLI for you.

## Does the model stay in memory all the time?

No. Magnitude loads the model when an agent requests it, keeps it available while active, and unloads it after inactivity or when memory is needed. The model remains downloaded and selected.

## Does my data go to the cloud?

Not when using local models. Models, prompts, and files stay on your machine. Requests only leave the machine when you explicitly configure an external endpoint in Magnitude Harness.

## Can it run completely offline?

Yes. After Magnitude and a model are downloaded, local inference works without an internet connection.

## Can I use models outside the catalog?

Yes. Magnitude discovers compatible GGUF models in recognized Hugging Face Hub cache locations, including models outside its catalog.
