## Is Magnitude free and open source?

Yes. Magnitude is Apache 2.0 licensed. Local inference does not require a paid API key. Individual model licenses still apply, and optional hosted providers may charge for their services.

## Does Magnitude work offline?

Local inference can run offline once the required model and runtime files are downloaded. Downloading models or runtime components, fetching uncached catalog information, and checking for updates need internet access. Hosted models also require connectivity.

## What stays on my machine?

Local model inference runs on your computer. The Usage page stores local usage measurements, not prompt or response content. If you choose a hosted provider, those requests go to that provider.

Update checks send application/platform information and a pseudonymous installation identifier to Magnitude. Download endpoints also record download-request metadata. This is separate from your local token-usage history.

## How do updates work?

Magnitude checks for application updates shortly after startup and approximately hourly while running. In **Settings → Application updates**, you can turn **Auto-download updates** on or off; turning it off does not disable checks.

Use **Download update** when an update is available, then **Restart to update** when it is ready. Prepared updates can also be applied on a subsequent startup. Installation stops the current model and service; Linux may ask for package-manager authorization.

Application updates include the bundled CLI and service. Downloading a new model is a separate operation.

## Does closing the window stop inference?

No. Closing the window leaves Magnitude running in the background. **Quit Magnitude** stops the app, service, and local inference. **Stop model** only unloads the active model; a later request can load it again.

## Can Magnitude start when I sign in?

Enable **Launch at login** in Settings. Magnitude starts in the background without opening its window. On Linux this requires a desktop login session; it isn't a system-wide boot service.

## Where are models and settings stored?

Magnitude uses `.magnitude` in your home directory: `~/.magnitude` on macOS/Linux, or `%USERPROFILE%\.magnitude` on Windows.

- `models/`: downloaded Magnitude models.
- `config.json`: user configuration.
- `cache/`: cached and derived data.
- `harness-connections.json`: connection management records.

Do not delete the whole directory to troubleshoot a single issue. Removing the app and removing your model data are different actions.

## Do I need npm or a separate CLI?

No. The desktop includes the CLI. See [CLI reference](/reference) for commands and [troubleshooting](/troubleshooting#magnitude-command-not-found) if your terminal cannot find it.

## Can I use a machine without a GPU?

Yes. CPU inference is supported, including Intel Macs and the current Windows build. Smaller models are generally more practical. See [Hardware](/hardware) for supported configurations and trade-offs.

## How do I change the theme?

Open Settings and select **Light**, **Dark**, or **System** appearance.
