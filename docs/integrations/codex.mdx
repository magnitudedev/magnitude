## Connect

1. [Install Codex](https://developers.openai.com/codex/cli) if needed.
2. Download a compatible model in Magnitude.
3. Open **Connections → Codex** and click **Connect**.
4. Select a downloaded model on the connected card, then click the command to copy it.
5. Paste it into your terminal from your project folder. On Windows, use PowerShell.

Magnitude configures Codex’s local gateway and model catalog. Local model IDs use the `magnitude-local/` prefix inside Codex. Keep Magnitude running while connected, including when you select a hosted model: hosted requests pass through the gateway to their provider. Disconnect in Magnitude and restart Codex before using it independently again.

## Run Codex

After connecting in Magnitude, start Codex with:

```sh
codex -c model_provider=magnitude --model magnitude-local/MODEL_ID
```

Replace `MODEL_ID` with the exact model ID, such as `gemma-4-e2b-it-qat:gguf:q4`, rather than its display name. The command shown in **Connections** already includes the correct ID for your selected model, so you can copy it without editing. Keep Magnitude running; it loads the model when the agent requests it.

## Configuration

**Connect** writes `~/.codex/config.toml`, `~/.codex/magnitude.config.toml`, and `~/.codex/magnitude.models.json`. Location overrides: `CODEX_HOME`.

Write the configuration yourself only when the agent runs where Connections cannot reach it, such as another device or WSL; see [Other devices](/api/other-devices) for `ADDRESS` and `API_KEY`.

`~/.codex/config.toml`:

```toml
model_provider = "magnitude"
model = "magnitude-local/MODEL_ID"

[model_providers.magnitude]
name = "Magnitude"
base_url = "http://ADDRESS:10100/inference/v1/proxies/codex"
wire_api = "responses"
env_key = "MAGNITUDE_API_KEY"
```

Export `MAGNITUDE_API_KEY` with the API key before starting Codex. Codex warns that model metadata is not found and continues. Only local models are available from another device.
