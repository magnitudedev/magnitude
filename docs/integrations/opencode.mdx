## Connect

1. [Install OpenCode](https://opencode.ai/docs/#install) if needed.
2. Download a compatible model in Magnitude.
3. Open **Connections → OpenCode** and click **Connect**.
4. Select a downloaded model on the connected card, then click the command to copy it.
5. Paste it into your terminal from your project folder. On Windows, use PowerShell.

Choose a Magnitude model in OpenCode’s model selector. If you use JSONC or an explicit OpenCode config, check the configuration paths shown in Connections: OpenCode can merge more than one file.

## Run OpenCode

After connecting in Magnitude, start OpenCode with:

```sh
opencode --model magnitude/MODEL_ID
```

Replace `MODEL_ID` with the exact model ID, such as `gemma-4-e2b-it-qat:gguf:q4`, rather than its display name. The command shown in **Connections** already includes the correct ID for your selected model, so you can copy it without editing. Keep Magnitude running; it loads the model when the agent requests it.

## Configuration

Default configuration files:

- `~/.config/opencode/opencode.json`

On Windows, `~` means your user profile directory.

Supported location overrides: `OPENCODE_CONFIG`, `XDG_CONFIG_HOME`. The paths displayed in Connections show which files Magnitude is actually checking.

## Repair or disconnect

If Connections shows **Connection needs repair**, click **Repair connection**. To stop using the integration, click **Disconnect**, then restart the agent.

See [connection states](/integrations/overview#connection-states) if the agent is not detected or its configuration cannot be verified.
