## Connect

1. [Install Claude Code](https://code.claude.com/docs/en/overview) if needed.
2. Download a compatible model in Magnitude.
3. Open **Connections → Claude Code** and click **Connect**.
4. Select a downloaded model on the connected card, then click the command to copy it.
5. Paste it into your terminal from your project folder. On Windows, use PowerShell.

Magnitude configures Claude Code’s gateway. Local model IDs use the `anthropic-local/` prefix. Keep Magnitude running while connected, including for hosted models: hosted requests still go to their provider through the gateway. Disconnect and restart Claude Code before using it independently again.

## Run Claude Code

After connecting in Magnitude, start Claude Code with:

```sh
claude --model anthropic-local/MODEL_ID
```

Replace `MODEL_ID` with the exact model ID, such as `gemma-4-e2b-it-qat:gguf:q4`, rather than its display name. The command shown in **Connections** already includes the correct ID for your selected model, so you can copy it without editing. Keep Magnitude running; it loads the model when the agent requests it.

## Configuration

**Connect** writes `~/.claude/settings.json`. Location overrides: `CLAUDE_CONFIG_DIR`.

Write the configuration yourself only when the agent runs where Connections cannot reach it, such as another device or WSL; see [Network access](/api/network-access) for `ADDRESS` and `API_KEY`.

`~/.claude/settings.json`:

```json
{
  "env": {
    "ANTHROPIC_BASE_URL": "http://ADDRESS:10100/inference/anthropic/proxies/claude-code",
    "ANTHROPIC_AUTH_TOKEN": "API_KEY",
    "CLAUDE_CODE_ENABLE_GATEWAY_MODEL_DISCOVERY": "1"
  },
  "model": "anthropic-local/MODEL_ID"
}
```

Only local models are available from another device.
