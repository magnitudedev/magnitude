# Hardware product images

Bundled product photography for enclosure and graphics-card families. Manufacturer renders use transparent or plain backgrounds; no credits, licenses, captions or source links appear in the app. `inventory.json` retains the source page and original image URL for maintenance. Surface product renders are supplied by retail product listings; other images come directly from manufacturers.

Match the observed device manufacturer and model before considering a graphics-card family. Apple model identifiers follow Apple’s device-identification pages. Processor variants in the same enclosure share a photo; unknown enclosures and laptop GPU suffixes never inherit an unrelated desktop image. GPU photos represent the card family, not a detected board vendor or cooler. The DGX A100 match uses the exact NVIDIA DMI product recorded in the [SPEC hardware report](https://www.spec.org/accel2023/results/res2023q4/accel2023-20231027-00005.pdf), never the presence of an A100 GPU alone.

Do not replace these with user-uploaded snapshots, scenes, benchmarks, boxed products, or close-up crops. Preserve the complete hardware silhouette. Native discovery remains authoritative for processor, accelerator and memory details; this inventory only selects artwork.
